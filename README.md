# sql-mysql-detective-club

![Data Detective Club Banner](assets/banner.png)

Welcome to the **Data Detective Club** 🕵️‍♂️ — a MySQL learning series where every lesson is a case to solve. Learn SQL fundamentals by cracking mysteries hidden in the data. Perfect for beginners who want to learn SQL in a fun, story-driven way.

## 📚 SQL topics covered in this series

### 🟢 Beginner — the basics
| ✔️ | Concept | Description |
|---|---------|-------------|
| ✔️ | SELECT | retrieve and view data |
| ✔️ | WHERE | filter data based on conditions |
| ✔️ | ORDER BY | sort query results |
| ✔️ | LIMIT | restrict the number of rows returned |
| ✔️ | DISTINCT | remove duplicate rows |
| ✔️ | AS (aliasing) | rename columns/tables for readability |
| ✔️ | Comments | writing readable, documented SQL |

### 🟡 Intermediate — combining & aggregating
| ✔️ | Concept | Description |
|---|---------|-------------|
| ✔️ | INNER JOIN | match rows that exist in both tables |
| ✔️ | LEFT JOIN | keep all rows from the left table |
| ✔️ | RIGHT JOIN | keep all rows from the right table |
| ✔️ | FULL JOIN (workaround) | combine LEFT + RIGHT via UNION |
| ✔️ | GROUP BY | summarize and aggregate data |
| ✔️ | HAVING | filter aggregated/grouped results |
| ✔️ | Aggregate functions | COUNT, SUM, AVG, MIN, MAX |
| ✔️ | UNION / UNION ALL | combine results from multiple queries |
| ✔️ | Subqueries | queries nested inside another query |

### 🔴 Advanced — real detective work
| ✔️ | Concept | Description |
|---|---------|-------------|
| ✔️ | Self joins | join a table to itself |
| ✔️ | Common Table Expressions (CTE) | `WITH` clause for cleaner, reusable queries |
| ✔️ | Window functions | ROW_NUMBER, RANK, DENSE_RANK, PARTITION BY |
| ✔️ | CASE statements | conditional logic inside queries |
| ✔️ | String functions | CONCAT, SUBSTRING, TRIM, REPLACE, LIKE |
| ✔️ | Date & time functions | NOW, DATEDIFF, DATE_FORMAT |
| ✔️ | NULL handling | IS NULL, IFNULL, COALESCE |
| ✔️ | Views | saving a query as a virtual table |
| ✔️ | Indexes | speeding up query performance |
| ✔️ | Transactions | COMMIT, ROLLBACK, data integrity |
| ✔️ | Stored procedures | reusable, saved SQL logic |
| ✔️ | Triggers | auto-run logic on data changes |
| ✔️ | Constraints & keys | PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL |
| ✔️ | Normalization basics | designing clean, efficient database schemas |

## 🕵️ How it works

Each lesson is framed as a "case" — a mystery hidden inside a dataset. You'll write SQL queries to uncover clues, follow leads, and solve the case using real MySQL syntax.


## 🚀 Getting started

1. Clone this repository
2. Set up a local MySQL server (or use an online SQL sandbox)
3. Open the first case folder and follow the instructions in its README
4. Write queries, solve the mystery, and move to the next case
